# Au chalet

Les modes d’emploi de la maison : un site familial de procédures, consultable sur téléphone,
modifiable par toute la famille.

- **Lire** : `https://maison.<domaine>` (connexion automatique à la maison, code par email ailleurs)
- **Ajouter / modifier une fiche** : [Pages CMS](https://app.pagescms.org)
- **Imprimer les étiquettes QR** : `/etiquettes/`

## Développement

```bash
npm install
npm run dev
```

Documentation technique complète (stack, modèle de données, charte, déploiement) : [CLAUDE.md](./CLAUDE.md).
